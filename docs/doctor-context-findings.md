## 재현과 남은 범위

`python scripts/audit_doctor_context.py data/build.sqlite`는 DB를 읽기 전용으로 열어 위 범위를 집계한다. 게임 원문과 개별 파일 경로를 출력하지 않는다. 합성 fixture로 선택지를 박사로 귀속하지 않는지 검사한다.

파서나 데이터 해시 입력을 바꾸지 않았으며 전체 원본 갱신·데이터 발행 Actions는 필요하지 않다. 기존 검증된 데이터 묶음을 재사용한다. 변경된 UI를 위한 단위 검사·브라우저 검증은 유지한다.

실제로 박사와 대화하는 용례만 자동 추출하는 기능은 여전히 해결되지 않았다. 후속 단계는 공식 구조에 플레이어 화자/선택지 소유자를 명시하는 식별자가 있는지 조사하는 것이다. 근거가 없는 한 일반 선택지에 박사 ID를 붙이지 않는다. 프로필 본문·음원 연결도 별도 후속 작업이다.


## 사용성 피드백 반영

‘제삼자 언급 후보’라는 내부 분류명 대신 화면에는 ‘다른 사람에게 언급’으로 표시한다. 활성화 시 두 번째 인물 칸은 ‘언급되는 인물’, 추가 칸은 ‘대화 상대 · 선택’으로 역할을 설명한다. PC에서는 필터와 선행 스토리 체크를 같은 행에 놓고, 다음 행의 추가 입력과 짧은 회색 안내를 나란히 정렬한다. 모바일은 한 열로 펼친다. ‘후보’ 분류의 한계는 문맥 확인 안내로 전달하며 실제 대화 관계를 확정하는 기능으로 바꾸지 않는다.

추가 원본 스캔에서 한국어 Decision 명령 4,498개 중 206개가 options/values 대신 option1/value1 등의 옛 형식을 사용함을 발견했다. 현재 파서는 이 형식의 선택지 본문을 적재하지 않는다. 선택지 화자 식별자는 어느 형식에도 관찰되지 않았다. UI 수정과 분리해 옛 선택지 문법·다국어 구조 대응을 보강할 후속 과제로 기록한다. 이 누락을 임의의 박사 발화로 채우지 않는다.

# 현재 범위와 다음 점검

새 기능을 늘리기보다 검색의 정확성·안정성·코드 정리를 우선합니다. 공개 패치노트는 실질적인 기능 변화와 중요한 수정만 기록하며, 세부 개발 이력은 Git에 보존합니다.

## 현재 제공하는 기능

- 네 언어의 원문 문자열을 함께 검색하고, 검증된 같은 대사는 합쳐 페이지 언어를 중심으로 표시합니다. 검색어를 자동 번역하지 않습니다.
- 결과의 언어 버튼은 재검색 없이 대사와 열린 문맥의 표시만 바꿉니다. 별도 검색 언어 선택기·대조 모드는 없습니다.
- 이름·등록 별칭 일치와 가까운 상대 발화는 검색 보조 근거입니다. 직접 호칭이나 대화 상대를 확정하지 않습니다.
- 최근 검색의 추가 결과·열린 문맥·읽던 위치를 탭 메모리 한도 안에서 복원합니다. 문맥은 열 때만 조회하고 확장 시 기존 행을 재사용합니다.
- 원본 갱신은 일일 검사 후 검증된 변경만 PR로 제안하며 자동 병합하지 않습니다. 삭제된 파일과 언어 누락은 조사 대상으로 차단합니다.
- 서비스 안내는 상단 물음표 모달 하나로 열며, 직접 접근용 /help 주소를 유지합니다.

## 남은 점검

| 우선순위 | 항목 | 완료 기준 |
| --- | --- | --- |
| 1 | 모바일·키보드 실화면 검증 | 320/375/390/430px 및 가로 화면에서 자동완성·모달·푸터·가상 키보드·기록 복귀 확인. 현재 브라우저의 폭 변경 제약으로 미완료. |
| 1 | 검색 안정성과 성능 | 같은 스냅샷에서 결과 수·순서·출처를 보존하고 조회/화면 중복 처리를 측정해 개선. 로컬 수치를 운영 속도로 주장하지 않음. |
| 2 | 실제 원본 변경의 자동 갱신 검증 | 새 SHA에서 후보 생성·전체 대응 검사·중복 없는 PR 생성까지 확인. 변경 없음 경로는 확인됐지만 실제 새 원본 전체 경로는 아직 남음. |
| 2 | 공개 범위·지원 명령 정확성 | 한국어 파일 존재 여부로 판단하는 공개 범위의 한계와 미지원 텍스트 명령을 조사. 파일명을 공식 제목이나 인물 관계로 추정하지 않음. |

## 음성 범위

별도 캐릭터 음성 검색 화면은 제거했습니다. 기존 스토리 검색 결과의 대사와 실제 음원 사이의 출처·언어·대응이 검증된 경우에만 재생을 검토합니다. 현재 재생 가능한 연결을 확보하지 못했으며 음성을 대신 추정하거나 효과음을 대사 녹음으로 붙이지 않습니다. [스토리 음원 조사](story-audio-status.md)와 집계 자료를 참고하세요. 캐릭터 음성 표에 대한 [선행 조사](voice-feasibility.md)는 구현 계획이 아닌 기록입니다.
